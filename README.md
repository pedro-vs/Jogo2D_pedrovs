# PedroVS Project

Este é um jogo desenvolvido por Pedro Henrique Vargas Sepulveda utilizando a engine Unity com exportação para WebGL.

## 🎮 Sobre o jogo

O PedroVS Project é um jogo interativo que roda diretamente no navegador. O objetivo é proporcionar uma experiência simples mas divertida.

## 🕹️ Como jogar

- Utilize o teclado para movimentar o personagem
- Pegue as moedas antes do tempo acabar

## 🎯 Objetivo

O jogador deve pegar as moedas antes que o tempo acabe.

## 🚀 Tecnologias utilizadas

- Unity (WebGL)
- C#

## 💻 Como executar

1. Baixe o projeto ou acesse via itch.io
2. Abra no navegador
3. Aguarde o carregamento
4. Clique em "Play" e comece a jogar
